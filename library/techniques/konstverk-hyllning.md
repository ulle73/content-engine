# Hyllning till ett känt konstverk  (`teknik.konstverk-hyllning`)

**Roll:** krok · **Medium:** video, carousel

Återskapa ett känt (fritt) konstverk med vår figur – igenkänningen stoppar scrollen, sedan bryts verket upp till verkligheten.

## Så går den till
Verket ritas i kod (aldrig nedladdat), figuren i verkets pose, verket rivs/öppnas till riktiga bilder.

## Varför den fungerar
Omedelbar igenkänning + överraskning (vår figur i verket); delbart.

## Tajming
Verket 5–6 s med text, rivningen på ett ljudslag.
