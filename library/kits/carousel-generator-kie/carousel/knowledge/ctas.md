# 05 — CTAs (last slide)

One clear action. Don't stack three asks — pick the single most valuable one.

## Formulas
- **Comment-to-DM (great for reach):** "Comment **\"[word]\"** and I'll send you [the thing]."
- **Follow:** "Follow **@handle** for more [topic]."
- **Save:** "**Save** this so you can [do it later]."
- **Try it:** "Go **build** it today — [where/how]."
- **Two-step:** big action line + a soft "follow for more" in the footer.

## Examples
- ✅ "Comment **\"books\"** and I'll send you the safe way to set it up."
- ✅ "Go build with it **today** — default on Claude Max."

## Tips
- The **comment-a-word** CTA drives the most engagement (comments + DMs). Use a short, memorable word.
- Keep your **@handle** on every slide's footer so shares stay attributed.
- End on the warmest / most inviting image in the set (sunset, open sky, etc.).
- Optional: a small recap of the 2–3 best facts as chips.
