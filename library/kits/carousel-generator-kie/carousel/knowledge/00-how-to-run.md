# 00 — How to run (read this first, Claude)

This is the master flow for the Carousel Generator kit. When the user asks for a
carousel, follow this exactly. The user should do almost nothing.

## Flow
1. **Read the knowledge base**: `structure.md`, `hooks.md`, `ctas.md`, `backgrounds.md`,
   `mascots.md`, `data-and-screenshots.md` (all in this folder). Apply them.
2. **Style is fixed** to the single bundled reference: `library/kits/carousel-generator-kie/carousel/assets/carousel-style-reference.png`.
   Never use another reference sheet. Ready mascot cutouts are in `library/kits/carousel-generator-kie/carousel/assets/mascots/`
   (`voxel_hook`, `voxel_coin`, `voxel_dash`, `voxel_mascot`) — reuse them; only regenerate if asked.
3. **Ask the user 5 questions** and wait: (1) topic or full script, (2) research-vs-user-provides,
   (3) slide count 5–7, (4) @handle + brand line, (5) mascot yes/no.
4. **Write the copy** (hook → body → CTA), build the plan, and **show it for approval**.
   Do NOT generate paid images before the user says go.
5. **Generate → render → export** after approval (all via kie.ai — the user's own KIE_API_KEY):
   - `library/.venv/Scripts/python library/kits/carousel-generator-kie/carousel/scripts/carousel_run.py init "<topic>"` → run folder + plan.json
   - Edit `plan.json`: per slide set `image_prompt` (the background scene, per `backgrounds.md`),
     plus `headline`/`hero_word`/`subtitle`/`topic_tag`, `content`, `mascot`. Leave `bg_file` empty —
     the generate step fills it. Use bundled mascots from `assets/mascots/` in the `mascot` field.
   - `library/.venv/Scripts/python library/kits/carousel-generator-kie/carousel/scripts/carousel_run.py generate <run>` → kie.ai **Nano Banana Pro**
     paints each background from the bundled style reference (needs KIE_API_KEY). PAID.
   - `carousel_run.py render <run>` → 1080×1350 PNGs.
   - `carousel_run.py export <run>` → `work/carousel-generator-kie/output/<slug>/`.
   - (Or `carousel_run.py produce <run>` = generate + render + export in one step.)
   - Show the user the finished images.

   Backgrounds are generated by the script (kie.ai) — you do NOT call any image MCP.
   Just write a good `image_prompt` per slide; the script sends it to kie with the bundled
   reference as the style. If a new mascot is needed (rare), the bundled cutouts usually suffice.

## Hard rules
- Titles are code-rendered by the template — never AI text.
- ONE reference sheet only.
- Approve-before-paid-generation (image credits cost money).
- 5–7 slides; one idea per slide; the middle of every slide carries a visual (chart/stat/mascot/screenshot) — never empty.
- Verify facts/numbers; attribute real screenshots ("via …").

## Plan fields (per slide)
`index, topic_tag, headline, hero_word (accent), subtitle, content, mascot, bg_file`.
`content` types: `image` (screenshot/hero), `hero` (mascot), `bars`, `stats`, `chips`.
For the 90s-film template add `kicker, hero_phrase, timestamp, filmtag` and set
`"template":"template-90s.html"` on the plan. (Default template = pastoral.)
