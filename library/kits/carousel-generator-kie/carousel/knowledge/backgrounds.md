# Background prompts

Backgrounds are generated by the script via **kie.ai Nano Banana Pro** — you don't call
any image tool yourself. Just write one good `image_prompt` per slide in `plan.json`; the
`generate` step sends it to kie together with the bundled style reference (as `image_input`)
and downloads the result. So: write the SCENE + the style instruction below, per slide.

## The universal template (put this in each slide's `image_prompt`)
```
[SCENE for this slide].
Use the supplied style sheet ONLY as a color, mood, and photographic-style reference —
match its palette, grain, and lighting. Vertical 4:5.
Keep the TOP HALF calmer / more open for a headline.
Absolutely NO text, no letters, no logos, no UI, no panels, no color swatches — only the scene.
```
- **Aspect ratio:** 4:5 (Nano Banana Pro supports it natively; set in config). Cover-fit handles any ratio.
- **Keep the top open** so the headline has room.
- **"No text/UI/panels"** stops the model copying the style sheet's own labels.
- Keep the **same style sentence** across all slides so the set matches.

## If you can't attach the reference (text-only look)
Describe the aesthetic in detail. Example (90s film):
```
[SCENE]. Shot on 90s film (Kodak-style): heavy film grain, soft orange halation / light leak,
lifted blacks (never pure black), cream-toned whites, muted faded colors, deep indigo sky fading
to haze, warm nostalgic travel-diary mood, low angle, slight vignette, disposable point-and-shoot look.
Keep the upper-left calmer for headline space. No text, no letters, no logos, no people.
```

## Scene ideas
- **Match the world of your style sheet** (the example photos in it). Pastoral sheet → meadows/hills. Film-travel sheet → temples/torii/streets.
- Vary each slide's scene a little (different angle/subject) so it's not repetitive, but keep one palette/finish.
- Pure atmosphere beats literal clip-art. A story about accounting can live on beautiful travel scenes — the text carries the message.
