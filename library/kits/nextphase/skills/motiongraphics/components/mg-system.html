The motiongraphics system

Everything in the house style, in one place and all of it running live: the ten scene layouts a beat can be staged in, the light leak that joins them, the seventeen motion devices that fill them, and the palette, materials and frame-counted cadence underneath. Reverse-engineered from six reference edits; every colour and duration is measured, not chosen.

Every word on these stages is placeholder. The bricks carry realistic copy so they render in a browser — none of it describes your video. In a real edit each string is derived from that recording: captions from the speaker's own words, labels from the thing actually being described, stats from the real verified figure, media from real sourced screenshots. scripts/check-placeholders.sh fails the render if any of it survives.

Part two

The light leak

The signature transition and the loudest thing in the style: 12 frames — bloom 5, white-out 3, reveal 4. The incoming scene is composited underneath the leak from the first frame, so this is a wash over a hard cut, never a dissolve. Always carries a swoosh with a riser cresting on the white-out.

Part three

The seventeen devices

Scenes are where a beat is staged; devices are what moves in it. One device per beat — two is a collision, not a composition. The only pairing that works is a ground plus one thing on top.

Part four

The palette

One accent per frame — violet or magenta, never both fighting. Coral is reserved for brand marks and is never a background. --alert is semantic and sits deliberately off the violet ramp so it can never read as brand colour.

Part five

The materials

Every object in the style is one of these. Nothing has a hard edge without a halo — every lit edge is 2px and carries a two-layer glow: a tight ring and a wide bloom. A single-layer shadow reads as a sticker.

Part six

The measured cadence

Frame-counted at 30fps off the references, not rounded to convenient values. These numbers are what make an edit read as this style rather than merely resemble it.

MoveFramesWhat actually happens
Word build8f / 267msEach word fades up over 8f, onsets 7f apart — and the whole line re-centres continuously as it grows.
Bar wipe12f / 400msscaleX from the left, leading edge brightest. The word inside fades in after the bar passes it.
Light leak12f / 400msBloom 5f, white-out 3f, reveal 4f. The next scene is already underneath from frame one.
Blur swap4f + 4fText becomes the next text through blur — out over 4, in over 4. Never a crossfade.
Ring draw18f / 600msSweeps clockwise, but starts ~0.5s after the lockup settles — a deliberate second beat.
Camera pull-backwhole sceneOne unbroken zoom-out, ease:none. Not discrete re-fit steps — those read as a layout reflowing.
Tile pop5f / 180msScale .86 → 1 with overshoot, siblings on a 90ms stagger.
Exit3f / 100msElements are gone, not dissolved. A half-second fade-out breaks the cadence immediately.
Handoff overlap2f / 67msThe incoming element is on screen while the outgoing one is still leaving. Never a gap.
Part seven

What this style never does

Never a still frame

Every held scene carries a slow drift. It's the difference between a motion graphic and a slide, and how a composition holds 25s without dying.

Never a hard edge without a halo

Every lit edge is 2px with a two-layer glow — a tight ring and a wide bloom. One layer reads as a sticker.

Never full-bleed media

Real screenshots and recordings are always an object on a stage, inside a rimmed card. Never letterboxed, never edge to edge.

Never typeset text as support

Every supporting beat shows a real resource. The point stack is the single exception the style allows.

Never emoji

Designed marks only — a coral asterisk drawn as SVG, a flat pictogram, a CSS arrow. Dingbat characters render as colour emoji on some platforms.

Never two accents fighting

Violet or magenta, one per frame. Coral is for brand marks. If everything is magenta, nothing is.

Never wall-to-wall graphics

Clean face is 30–40% of the runtime. The reference cuts 20 times in 190 seconds. The breathing is what makes the next beat land.

Never a silent cut

Every layout change carries a transition and a sound, at 12–20 cues a minute. The light leak is an event and is mixed like one.
