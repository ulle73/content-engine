17 devices · learned from four reference grids

The motion library

Four reference clips, each a 2×2 grid, gave 17 distinct motion devices. Every one is rebuilt here in the motiongraphics token set — our violet, our faces, our measured cadence. These are devices, not scenes: each one drops into the ten layouts the skill already defines. All of it is CSS and SVG; there are no assets and no video.
