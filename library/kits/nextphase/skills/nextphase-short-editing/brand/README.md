# brand/ — logotyper (originalen borttagna)

Kitet skeppade tredjepartsvarumärken (Claude/Anthropic, ChatGPT/OpenAI, Gemini, GitHub, Perplexity, X)
och Claude Code-ordmärken. De är andras varumärken och togs bort vid importen.

Filerna här är **neutrala platshållare** (en bokstav i en cirkel) med samma filnamn, bara så att
`ui-blocks/` och `components/tier-board.html` renderar. Ersätt med riktiga loggor för det du
faktiskt visar (t.ex. Golfkupongers egen logga eller en banas logga du har rätt att visa) — samma
filnamn, eller ändra `src` i blocket.
