# mascot/ — maskotens sprites (platshållare)

Originalet (`clawd/`, 72 filer) var Anthropics Claude-maskot — varumärkesskyddad och inte
licensierad för vidarespridning — och togs bort vid importen.

`outline/mascot-<pose>.webp` är en **egen neutral platshållare** (en pixel-golfboll) genererad vid
importen, med samma posnamn som blocken använder (`thinking`, `happy`, `carrying`, `debugger`,
`typing`, `conducting`, `idle`, `building`, `sleeping` …). Byt mot en egen karaktär (samma filnamn,
transparent WebP, ~256 px) — t.ex. en Golfkuponger-figur.

Används av `ui-blocks/sessions-grid.html`, `ui-blocks/sessions-hub.html` och `scripts/build-blocks-page.py`.
