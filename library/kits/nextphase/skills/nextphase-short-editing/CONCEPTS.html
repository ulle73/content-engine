What to show, for what he says.

The editor's lookup. Read it before choosing any asset: find what the line is about, use what's under it. Terms and counts are mined from the 22 shipped transcripts, so the list is what he actually talks about — not what the library happens to contain. Every block below is live and animating, not a screenshot.

  1. A PRODUCT is shown as its real UI, animated. Never a mascot standing in for a product.
  2. A MASCOT is only ever the actor — the thing tending, carrying, conducting or reacting. It is never the session, the model, the app or the file.
  3. If he names a tool, that tool's own UI is on screen on the word.
  4. Plural concepts get plural UI. 'sessions' is more than one window, not one window.
  5. No small text — see reference/BLACKLIST.md #1. If the only asset is a text screenshot, build a block instead.
  6. A page screenshot is shot FOR ITS SLOT: b-roll full = a true 9:16 frame; split = the marker band in the top half; transparent = a card above his head. Never one crop reused in all three.
