# reference/stills/ — referensbilder (borttagna)

Originalkitet hade här stillbilder, kontaktark och 2–4×-beskärningar ur **andra kreatörers videor**
(referensklippen som stilen mättes från). De får inte spridas och togs bort vid importen.

Alla mått som betyder något finns kvar i textform i `reference/*.md` (särskilt `reference-log.md`)
och i `assets/tokens.css`. Visuell referens i stället: `components/*-system.html` och
förhandsbilderna i `library/previews/nextphase.vibecode.*.jpg`.
