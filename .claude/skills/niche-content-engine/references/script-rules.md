# Script rules

## Shape
1. **Hook (0–3s):** one sentence, ~12 words. Carries the tension: money, danger, a mistake, a
   secret, or a picture that makes people stop. No intro, no name, no "in this video".
2. **Re-hook (3–6s):** one line that makes them stay. "And number three is the one nobody checks."
3. **Body:** 3 beats max. Each beat = one concrete thing + why it matters. Use real trade detail.
4. **Tip / payoff:** one line they can use even if they never call you.
5. **CTA:** "Comment WORD and I'll send you the ___" — or "Call/DM us, we're in {city}".

## Voice
- Written to be said out loud: contractions, short sentences, one line allowed to run long.
- Sound like the user, not an ad. If they gave examples of how they talk, match them.
- Second person — "your roof", "your quote".
- One idea per sentence. If a sentence needs a comma to breathe, split it.

## Truth rules
- **No invented numbers, stats, reviews, or stories.** Use numbers the user gave, or numbers you
  verified from a named source (put the link in the notes, not the script).
- If a price is needed and you don't have one, say "ask for the per-square price on your quote"
  instead of guessing a figure — or ask the user for their real range.
- **No brackets or placeholders** in the finished script. Resolve every one.
- Medical, legal, insurance, financial topics: general education only, no promises.
- Never name or attack a competitor.

```
Why this: [the finding + link it came from]

"..."

B-ROLL: close-up of curled shingles · granules in the gutter · attic flashlight shot
CAPTION: 1–2 lines + 3–5 niche hashtags + the keyword line
DELIVERABLE TO SEND: "Storm-season roof checklist" — 8 items (outline below)
```

## Final check before handing over
- [ ] Hook works with the sound off (on-screen text says it too)
- [ ] 90–160 words, reads naturally out loud
- [ ] One real pro detail
- [ ] No brackets, no made-up numbers
- [ ] CTA keyword unique in the batch, deliverable exists or is outlined
- [ ] Would this bring a lead or build trust? If not, cut it.
